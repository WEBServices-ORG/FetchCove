Data and privacy

Your media stays on your Mac.

FetchCove runs download and media-processing tools locally. It does not require a FetchCove account or upload your downloads to a FetchCove server.

Media sources and updates

When you inspect or download a link, the selected engine connects to the media source and any services it needs. Source sites receive those requests under their own policies. Explicit update checks contact the relevant release provider; tool updates run only after you choose them.

Settings and optional history

Tool paths, your chosen folder and download settings are saved locally. Remembering execution details is off for each new job. If you turn it on, that job's inputs, arguments, paths and results are stored in macOS Keychain. The private history file contains references and status. It does not store console output or prompt replies.

Remembered downloads also use an encrypted receipt beside their completed files so an interrupted job can recognize verified output. Forget removes the selected history record and its Keychain details; it leaves your media and working files in place.

Output and credentials

FetchCove masks known sensitive values in its displayed diagnostics. This cannot cover every transformed value. Explicit raw-output files preserve exact bytes and may contain sensitive information. Review output before sharing it. Browser-cookie access and other authentication options run only when you explicitly configure and run them; source sites and selected tools control their behavior.

This website

The prepared static page contains no analytics, advertising scripts, remote fonts or embedded payment forms. The hosting provider may process ordinary web-request information when the site is published. Following an external link takes you to that provider's site.

Support

Support links open PayPal for optional contributions. PayPal handles the payment process. If you email support, the information you choose to include is sent through your email service.
